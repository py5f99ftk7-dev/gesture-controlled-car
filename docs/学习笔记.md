### RAM、SRAM、Flash 的区别
- 分类：一、ESP32 基础
- RAM 是运行内存，放变量和堆栈，断电丢失；单片机片内 RAM 就是 SRAM，报告里的 RAM 占用即 SRAM 占用。
- Flash 断电不丢，存代码、常量、字库。
- 编译报两项占用：Flash 超了装不进芯片；RAM 超了堆栈变量不够，容易死机重启。
- 对照 STM32：片内 SRAM 对应这里的 RAM，片内 Flash 对应 Flash；Keil 同样报 Program Size 和 RAM 占用。

### PlatformIO 常用命令
- 分类：二、开发环境与工具链

  编译：
  - `pio run`：编译当前工程。
  - `pio run -v`：详细日志。
  - `pio run -d 路径`：指定工程目录。
  - `pio run -e 环境名`：只编指定环境。
  - `pio run -t clean` / `-t fullclean`：清理编译产物。

  烧录与串口：
  - `pio run -t upload`：编译并烧录。
  - `pio run -t monitor`：打开串口监视器。
  - `pio run -t upload -t monitor`：烧录后直接看串口。
  - `pio device list`：列出串口设备和芯片型号。
  - `pio device monitor`：不重编，直接看串口。

  查看工程：
  - `pio project config`：板型、框架、串口速率、库依赖。
  - `pio lib list`：已装库；`pio platform list`：芯片平台版本。
- 状态：已验证

### 回调与回调类型
- 分类：三、通信与无线
- 回调：自己写一个函数交给库，事件发生时由库自动调用，不用主循环一直查。STM32 里类似中断服务函数，事件一来自动进函数。
- 回调类型：规定回调函数的外形——几个参数、各是什么类型、返回值。例：ESP-NOW 接收回调类型 `esp_now_recv_cb_t`，外形是 `void(const uint8_t *mac, const uint8_t *data, int len)`，函数外形对不上就注册不了。
- 状态：已验证

### 版本不匹配类报错的判断方法
- 分类：五、调试方法与报错经验
- 先确认本机框架版本：编译日志 PACKAGES 行，或 `pio project config`。
- 再去本机框架头文件里搜报错的类型名、函数名：搜得到是写法对，搜不到是当前版本没有，属版本不匹配。
- 整组写法（回调参数、初始化函数、输出方式）一起变，是版本差异；单个词拼错才是手误。
- 对照本机旧版写法改代码，比下载新版框架省时间。
- 状态：已验证
