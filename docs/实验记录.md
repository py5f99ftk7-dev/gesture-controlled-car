## 2026-11-20
### 车端编译报错：API 版本不匹配
- 现象：三处报错——`esp_now_recv_info_t` 未定义；`ledcAttach` 未声明；接收回调签名与 `esp_now_recv_cb_t` 不匹配。
- 排查：pio run 日志确认本机框架 framework-arduinoespressif32 2.0.11；报错涉及的类型和函数在本机头文件中搜不到。
- 定位：代码按 Arduino-ESP32 新版写法编写，本机是 2.0.11 旧框架，类型和函数对不上。
- 改法：
  1. 回调首参由 `esp_now_recv_info_t*` 改为 `const uint8_t *mac`；
  2. `ledcAttach(引脚, 频率, 分辨率)` 拆成 `ledcSetup(通道, 频率, 分辨率)` + `ledcAttachPin(引脚, 通道)`，用通道 0、1；
  3. `ledcWrite` 改为按通道输出。
- 结果：SUCCESS，RAM 13.0%，Flash 55.2%，车端固件生成成功
